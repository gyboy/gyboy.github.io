计算公式与说明

设电压衰减比 a = 10^(A/20)（A 为衰减量，单位 dB），源阻抗与负载阻抗相等（均为 Z₀）：

R₁ = R₃ = Z₀ · (a + 1) / (a − 1)　（输入 / 输出端并联电阻）

R₂ = Z₀ · (a² − 1) / (2a)　（串联电阻）

功耗估算（衰减器两端匹配时）：V₁ = √(P_in · Z₀)，V₂ = V₁ / a

P(R₁) = V₁² / R₁　，　P(R₂) = (V₁ − V₂)² / R₂　，　P(R₃) = V₂² / R₃

标称值取与计算值最接近的 E24（5% 精度）与 E96（1% 精度）系列电阻。

小提示
  • 射频场景建议使用 1% 精度金属膜电阻，并尽量选小封装以降低寄生电感。
  • 大衰减时绝大部分功率消耗在 R₁ 上，选型时重点关注它的额定功率。
  • 衰减量接近 0 dB 时，并联电阻趋于无穷大，此时应改用 T 型网络或其他方案。
