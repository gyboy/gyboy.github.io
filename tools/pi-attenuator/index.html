计算公式与说明

设计模式（对称网络，电压比 a = 10^(A/20)，A 为衰减量 dB）：

π 型：R₁ = R₃ = Z₀·(a+1)/(a−1)（两端并联），R₂ = Z₀·(a²−1)/(2a)（串联）

T 型：R₁ = R₃ = Z₀·(a−1)/(a+1)（两端串联），R₂ = 2Z₀·a/(a²−1)（并联）

反算模式（ABCD 矩阵法，支持非对称网络）：

π 型：A = 1+R₂/R₃，B = R₂，C = 1/R₁+1/R₃+R₂/(R₁R₃)，D = 1+R₂/R₁

T 型：A = 1+R₁/R₂，B = R₁+R₃+R₁R₃/R₂，C = 1/R₂，D = 1+R₃/R₂

Z_in = √(AB/CD)，Z_out = √(DB/AC)，衰减 = 20·lg(√(AD)+√(BC))

网络不对称时 Z_in 与 Z_out 不相等，衰减按两端影像阻抗匹配端接定义；对称时两者同为 Z₀。

功耗估算：以源内阻 Z_in、负载 Z_out 端接（影像匹配），节点电压法解出各电阻的电压电流，再按输入功率 Pin 缩放。

标称值取与计算值最接近的 E24（±5%）与 E96（±1%）系列电阻。

小提示
  • π 型与 T 型互为对偶：衰减量较小时 π 型的并联臂阻值极大、T 型的串联臂阻值极小，可按手头现成的阻值选择更容易实现的拓扑。
  • 衰减量大时约八成的功率消耗在 R₁ 上，选型时重点关注它的额定功率。
  • 反算模式下若三个电阻不对称，两端的影像阻抗不相等，衰减按影像匹配端接定义。
  • 射频场景建议使用 1% 精度金属膜电阻，并尽量选小封装以降低寄生电感。
