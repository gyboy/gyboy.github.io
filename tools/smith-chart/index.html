❓ 操作说明
  • 常规匹配流程：① 「数据点」面板添加 DP（负载阻抗）→ ② 在圆图下方「电路匹配拓扑」点 ＋ 插入器件 → ③ 单击器件上的数值就地改参数、双击器件删除 → 每个器件自动生成对应「节点」DP（表格底部 + 圆图方形标记带名称），圆图实时显示匹配轨迹与终点。
  • 拖动左右分隔条调整侧栏宽度；拖动圆图下方的分隔条调整拓扑区高度。
  • 滚轮缩放（以光标为中心），拖动空白平移；右下角「🔓」锁定视图防误操作，「⊡」复位。
  • 悬停圆图：实时显示 Γ / Z / Y / VSWR / RL / Q；双击圆图加点；拖动 DP 改阻抗。
  • 交互调谐（进阶）：选起点 → 点器件类型 → 拖动绿色手柄（轨迹末端）沿等 r / 等 g / 等|Γ| 圆滑动实时读值，松手直接写入下方拓扑（无需转换）；拖动起始 DP 时拓扑与节点数值同步更新；「L/π/T 型匹配」点方案直接替换拓扑（π/T 通过虚拟电阻级联两节 L，可按 Q 选择方案）。只有选中的起始 DP 参与匹配并显示轨迹，其余 DP 均为独立点（切换起始后轨迹随之切换）。双击/拖动 DP 自动吸附网格线（Alt 精确）。
  • 快捷键：+ / - 缩放，0 复位视图，Esc 取消模式，Del 删除选中 DP。
