计算公式与说明

正弦波：Vₚ = Vpp/2，Vrms = Vₚ/√2，Vavg = 2Vₚ/π（全波整流平均值）

方波（双极性 ±Vₚ、占空比 50%）：Vₚ = Vpp/2，Vrms = Vavg = Vₚ

平均功率：P = Vrms²/Z₀；dBm = 10·lg(P/1mW)，dBW = 10·lg(P/1W)

电压分贝：dBV = 20·lg(Vrms/1V)，dBµV = 20·lg(Vrms/1µV)

反算：按波形关系将输入电压还原为 Vrms（如正弦 Vrms = Vpp/(2√2)），再由 P = Vrms²/Z₀ 求功率。

速查：50 Ω 系统中 0 dBm ≈ 223.6 mVrms ≈ 632.5 mVpp（正弦）。

小提示
  • 功率计与频谱仪读数通常是 dBm；示波器读到的是电压，需已知阻抗与波形才能换算成功率。
  • 相同峰峰值时，双极性方波的有效值是正弦波的 √2 倍，功率大 3.01 dB。
  • 示波器高阻探头（1 MΩ）下不能套用 50 Ω 公式，请把 Z₀ 改为实际等效阻抗。
